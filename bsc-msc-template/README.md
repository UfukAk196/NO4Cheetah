# Thesis Template - Chair of Computational Mathematics (E-10)

Are you writing your Bachelor thesis, Master thesis or project report at TUHH's Chair of Computational Mathematics? Then you must use this LaTeX template for your thesis/report.

You will have to delete all the text that is already in there but make sure to read it first - carefully! It hopefully provides lots of useful tips and hints on how to be successful with your research project.

## Using GIT and LaTeX

If you are new to GIT and or LaTeX, there are tons of useful guides out there. Any modern LLM will also be able to help you.
